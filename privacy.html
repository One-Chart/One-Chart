Privacy Policy — One Chart

Last updated: 15 August 2026

What this application is

One Chart is a private publishing tool operated by a single individual. It renders data-visualisation videos from public statistics and uploads them to that same individual's own social media accounts. It is not offered to other users, has no sign-up, and holds no accounts other than the operator's own.

What data is accessed

When the operator authorises this application with TikTok, it receives an access token for the operator's own TikTok account. Using that token, the application may:

  • upload videos to the operator's own account;
  • read back public performance figures for the operator's own videos (view, like, comment and share counts), used to decide which topics to cover next.

No data belonging to any other TikTok user is requested, accessed or stored.

Where data is stored

Access and refresh tokens are stored in a local file (secrets/tiktok_token.json) on the operator's own computer. Performance figures are stored locally in the same way. Nothing is transmitted to any third-party server, and there is no hosted backend, database or analytics service.

What is not done

This application does not sell, share, rent or transfer any data to third parties. It runs no advertising, sets no cookies, and does not track visitors. It collects no information from anyone other than its operator.

Retention and revocation

Tokens are kept only while the integration is in use and are replaced automatically when they expire. The operator can revoke access at any time from TikTok's “Manage app permissions” settings, which immediately invalidates the stored token. Local token and statistics files can be deleted at any time.

Contact

Questions about this policy can be sent to the operator at the contact address listed on the TikTok developer application record.
